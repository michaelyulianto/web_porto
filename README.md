# Michael Yulianto Tamba — Portfolio

Website portfolio statis memakai HTML, CSS, dan JavaScript. Jalankan dengan membuka `index.html` di browser atau Live Server VS Code.

## Struktur

- `index.html` — konten semantik, navigasi, dan section.
- `style.css` — visual dan responsive layout.
- `script.js` — navigasi mobile dan tahun otomatis.
- `assets/` — foto profil.
- `projects/earth/` — halaman proyek Facts About Earth.
- `projects/3d-boxes/` — proyek 3D Boxes Background.

## Sebelum dikumpulkan

Ganti `hello@example.com` pada `index.html` dengan email asli. Deskripsi pribadi dan detail proyek dapat disesuaikan bila perlu. Seluruh navigasi internal dan tautan proyek menggunakan path lokal agar website dapat langsung dijalankan dari file ZIP yang diekstrak.

## Pemetaan rubrik

- Kelengkapan: biografi, navbar, list project yang dapat dibuka, kontak, plus Skills dan Approach.
- Kode: HTML semantik, CSS responsif, JavaScript terpisah, folder project terstruktur.
- Kreativitas: desain editorial grayscale, hero visual asimetris, responsive layout, feedback hover/fokus.
